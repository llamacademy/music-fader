# Simple Music Fader 

In this tutorial repository and [accompanying video](https://youtu.be/Lq_LS3lIRbU) you will learn how to fade between music tracks, smoothly and easily in Unity without needing complex FMOD or AudioMixer configurations.

[![Youtube Tutorial](./Video%20Screenshot.jpg)]([https://youtu.be/Lq_LS3lIRbU](https://youtu.be/Lq_LS3lIRbU))
